Figure 4.5: Dashboard Rendering Sequence Diagram

sequenceDiagram
    autonumber
    actor Browser as 🖥️ User Browser
    participant React as ⚛️ React UI\n(App.jsx / Dashboard.jsx)
    participant API as ⚡ Express API\n(server.js)
    participant DB as 💾 Database Store\n(db.json / database.js)

    Browser->>React: 1. Navigate to Dashboard (http://localhost:5173)
    activate React

    Note over React: 2. Read LocalStorage ('mqp_user') & inspect User Role\n['qa' | 'dev' | 'pm' | 'customer']

    React->>API: 3. GET /api/applications
    activate API

    API->>DB: 4. getApplications()\nFetch active Application & TestExecution record
    activate DB
    DB-->>API: 5. Return Application Entity (metrics, appiumDetails, mobsfDetails)
    deactivate DB

    API-->>React: 6. HTTP 200 OK Response (JSON Application Array)
    deactivate API

    Note over React: 7. Apply CSS Class to Body (view-qa / view-dev / view-pm / view-customer)

    alt Role == Project Manager (pm_admin)
        React->>React: Render Overall Quality Score Gauge Chart,\nRelease Recommendation Badge, Admin Console & Pending Approvals
    else Role == Mobile Developer (dev_lead)
        React->>React: Render Appium UI Locator Stack Traces,\nGit Commit Traceability Metadata & MobSF Patch Guidelines
    else Role == QA Engineer (qa_engineer)
        React->>React: Render Smart Upload Dropzone, Appium Donut Chart,\nAudit History Logs & Raw File Source Modals
    else Role == Customer / Client (client_user)
        React->>React: Render Executive Summary Box\n(Suppress technical stack traces & raw file payloads)
    end

    React-->>Browser: 8. Render Role-Customized Interactive Dashboard View
    deactivate React
