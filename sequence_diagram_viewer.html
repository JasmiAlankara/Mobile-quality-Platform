Figure 4.4: CI/CD Ingestion Sequence Diagram

sequenceDiagram
    autonumber
    actor Pipeline as 🚀 CI/CD Pipeline\n(GitHub Actions / Jenkins)
    participant API as ⚡ Express API\n(server.js)
    participant Parser as 🧩 Parser Engine\n(parser.js)
    participant DB as 💾 Database Store\n(db.json / database.js)

    Pipeline->>API: 1. POST /api/applications/:id/pipeline/ingest\n[Header: Authorization Bearer Token]\n[Body: Multi-Files XML/CSV/JSON + Git Metadata]
    activate API

    Note over API: 2. Validate Bearer API Token & Auth Permissions
    alt Token Invalid / Missing
        API-->>Pipeline: Return HTTP 401 Unauthorized / 403 Forbidden
    else Token Valid
        
        loop For Each Attached Report File
            API->>Parser: 3. detectReportType(fileContent, filename)
            activate Parser
            Parser-->>API: Return Detected Tool Format ('appium' | 'jmeter' | 'mobsf')
            
            API->>Parser: 4. parseReport(content, type)
            Note over Parser: Process XML (Appium) / CSV (JMeter) / JSON (MobSF)\nExtract test counts, latency, vulnerabilities & stacktraces
            Parser-->>API: Return Formatted Parsed JSON Domain Object
            deactivate Parser
        end

        API->>DB: 5. recalculateQualityMetrics(appData) & saveApplications()
        activate DB
        Note over DB: Compute Unified Score (30% UI + 35% Perf + 35% Sec)\nDetermine Release Recommendation Badge\nAppend to Build History List
        DB-->>API: 6. Confirm Database Save Success & Return Updated Record
        deactivate DB

        API-->>Pipeline: 7. HTTP 200 OK Response\n[JSON: { success: true, buildLabel, qualityScore, recommendation }]
    end
    deactivate API
