Figure 5.1: Flowchart of the Parser Engine Workflow

flowchart TD
    StartNode((● Start)) --> ReceivePayload[CI/CD Payload Received\nPOST /api/pipeline/ingest]
    ReceivePayload --> ExtractMetadata[Extract Git_Metadata\ncommitHash, branchName, author]
    ExtractMetadata --> ExtractFiles[Extract Files Array reports[]\nvia Multer Memory Storage]
    ExtractFiles --> InitReport[Initialize Unified_Report = {}]
    
    InitReport --> LoopStart{For Each File\nin Files Array}

    LoopStart -- Path 1: If XML / application/xml --> XMLBranch[Appium Parser Branch]
    LoopStart -- Path 2: If CSV / text/csv --> CSVBranch[JMeter Parser Branch]
    LoopStart -- Path 3: If JSON / application/json --> JSONBranch[MobSF Parser Branch]

    XMLBranch --> CallAppium[CALL Appium_Parser file]
    CallAppium --> ExtractUI[Extract passed_tests, failed_tests\n& assertion stack traces]
    ExtractUI --> AppendUI[Append to Unified_Report.functional] --> LoopNext

    CSVBranch --> CallJMeter[CALL JMeter_Parser file]
    CallJMeter --> CalcPerf[Calculate avg_latency_ms,\nthroughput & error_rate_pct]
    CalcPerf --> AppendPerf[Append to Unified_Report.performance] --> LoopNext

    JSONBranch --> CallMobSF[CALL MobSF_Parser file]
    CallMobSF --> CountSec[Count high_risk, medium_risk,\nlow_risk & patch guidelines]
    CountSec --> AppendSec[Append to Unified_Report.security] --> LoopNext

    LoopNext{More Files\nin Payload?} -- Yes --> LoopStart
    LoopNext -- No --> MergePaths[⚡ Merge Parsed Paths]

    MergePaths --> CalcScore["CALL Calculate_Unified_Score(Unified_Report)\nOverall Score = 30% UI + 35% Perf + 35% Sec\nReturns overallScore (0-100) & recommendation badge"]
    CalcScore --> LinkGit[LINK Unified_Report to Git_Metadata\ncommitHash, branchName, author]
    LinkGit --> SaveDB[SAVE Unified_Report & updated history\nto db.json Database]
    SaveDB --> ReturnOK[RETURN HTTP 200 OK to CI/CD Runner\nJSON: success, overallScore, recommendation]
    ReturnOK --> EndNode((◉ End))
