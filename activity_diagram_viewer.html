UML Activity Diagram — Parser Engine & Ingestion Workflow

flowchart TD
    StartNode((● Start)) --> ReceivePayload[Receive Upload File Payload\nDrag & Drop / CI Webhook]
    ReceivePayload --> ValidatePayload{File Payload\nValid?}
    
    ValidatePayload -- No --> RejectPayload[Return HTTP 400 Bad Request\nInvalid File Format Error] --> EndNodeBad((◉ End))
    ValidatePayload -- Yes --> DecisionMime{Decision Node:\nCheck File Content Header\n& Extension}

    DecisionMime -- If XML /  AppiumBranch[Route to Appium Parser Strategy]
    DecisionMime -- If CSV / JSON (JMeter) --> JMeterBranch[Route to JMeter Parser Strategy]
    DecisionMime -- If JSON (MobSF) --> MobSFBranch[Route to MobSF Security Parser Strategy]

    AppiumBranch --> ParseAppium[Extract testsuite attributes\ntests, failures, errors]
    ParseAppium --> ExtractStacktrace[Extract failed testcase names,\nclass paths & stack traces]
    ExtractStacktrace --> MapGitMetadata[Map Git Version Control Metadata\nCommit Hash, Branch Name, Author]
    MapGitMetadata --> AppiumOut[Appium Domain Object]

    JMeterBranch --> ParseJMeter[Stream transaction rows or\nJSON summary trees]
    ParseJMeter --> CalcJMeterAverages[Calculate Mean Latency ms,\nThroughput req/s, Error Pct]
    CalcJMeterAverages --> CheckErrorThreshold{Check Transaction\nError Pct <= 2.0%?}
    CheckErrorThreshold -- Yes --> AttachSafeBadge[Attach Safe Error Checkmark Badge] --> JMeterOut[JMeter Domain Object]
    CheckErrorThreshold -- No --> AttachErrorAlert[Attach Error Rate Alert] --> JMeterOut

    MobSFBranch --> ParseMobSF[Deserialize MobSF JSON tree]
    ParseMobSF --> CountSeverity[Count High, Medium, Low\nseverity vulnerability keys]
    CountSeverity --> AttachFixGuidelines[Extract vulnerability titles,\ndescriptions & Patch Guidelines]
    AttachFixGuidelines --> MobSFOut[MobSF Domain Object]

    AppiumOut --> JoinNode[⚡ Join Node:\nMerge Parsed Domain Objects]
    JMeterOut --> JoinNode
    MobSFOut --> JoinNode

    JoinNode --> NormalizeMetrics[Normalize Metrics to 0–100 Domain Scores:\nUI Score, Perf Score, Security Score]
    NormalizeMetrics --> ApplyFormula["Calculate Unified Score Formula:\nOverall Score = (30% * UI) + (35% * Perf) + (35% * Security)"]
    
    ApplyFormula --> ReleaseDecision{Release Recommendation\nDecision Tree}
    
    ReleaseDecision -- Score >= 90 & High = 0 --> RecReady[Assign 'RELEASE READY' Badge]
    ReleaseDecision -- High > 0 & High <= 2 --> RecSec[Assign 'NEEDS SECURITY IMPROVEMENTS' Badge]
    ReleaseDecision -- Score < 75 or High > 2 --> RecRefactor[Assign 'NEEDS REFACTORING' Badge]
    ReleaseDecision -- Score 75-89 & High = 0 --> RecTesting[Assign 'READY FOR TESTING' Badge]

    RecReady --> SaveDB[Save Build History & Quality Metrics\nto Relational Database db.json]
    RecSec --> SaveDB
    RecRefactor --> SaveDB
    RecTesting --> SaveDB

    SaveDB --> UpdateDashboard[Refresh Dashboard Gauges,\nDonut Slice, Sparklines & Badges]
    UpdateDashboard --> EndNode((◉ End))
